# 研究単語ノート

手書きメモから読み取った専門用語を日付ごとにまとめ、覚えたら☑で横線を引く単語帳です。
PC（Windows）と iPhone / iPad で同期します（Firebase）。

## ファイル
| ファイル | 役割 |
|---|---|
| index.html / style.css | 画面 |
| app.js | ログイン、一覧、編集、取り込み、同期 |
| parse.js | 読み取った文字を「日付・見出し・単語・補足・メモ」に分ける |
| firebase-config.js | Firebaseの設定 |
| sw.js / manifest.webmanifest / icon-*.png | オフライン対応とホーム画面アイコン |
| firestore.rules | Firestoreに設定したルールの控え（アップロード不要） |

## メモの書き方ルール（読み取り）
- 1〜3行目の「10/17」を日付にする（年は今年。1か月以上先になるときだけ前年）
- ①⑪など丸数字で始まる行は見出し → 下の単語のグループ名（空行で終わり）
- ○ ・ 。 で始まる行は単語（空行がなくても1行＝1単語）
- 印のない行は、直前に単語があればその補足、空行のあとならメモ

## ショートカットからの取り込み
`https://ユーザー名.github.io/tango-note/#import=（URLエンコードした文字）` で開くと、取り込み画面に文字が入った状態で開きます。
